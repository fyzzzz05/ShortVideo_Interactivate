接口清单

方法 路径 模块 说明 主要参数
GET /health system 服务健康检查。 -
GET /api/v1/dramas dramas 获取短剧列表。 -
GET /api/v1/episodes/{episode_id}/danmaku danmaku 查询某集弹幕，支持时间范围和分页。 start_ms end_ms limit offset
GET /api/v1/episodes/{episode_id}/events events 查询某集高光事件。mode=hybrid 会尝试合并实时检测。 mode=offline|hybrid
POST /api/v1/events/realtime-detect events 实时高光检测联调入口。 episode_id start_ms end_ms scene_hint
POST /api/v1/highlights/detect highlights 调用豆包模型批量识别高光，可选择自动导入 events 表。 segments drama_id episode_id auto_import
POST /api/v1/interactions/click interactions 互动点击上报。 episode_id highlight_dedup_key user_id
POST /api/v1/interactions/like interactions 互动点赞上报。 episode_id highlight_dedup_key user_id
GET /api/v1/interactions/summary interactions 获取某集互动汇总。 episode_id
POST /api/v1/shop/search-link shop 根据标签生成同款搜索链接。 tags
GET /api/v1/quiz/{episode_id}/profile quiz 获取某集剧末人格测试题。 episode_id
POST /api/v1/quiz/submit quiz 提交测验答案，返回角色画像。 episode_id answers

联调注意事项

后端默认读取 backend/.env，默认数据库路径是 sqlite:///./shortvideo.db。启动和导入数据时建议都在 backend/ 目录执行，避免生成另一个 SQLite 文件。

调用 /api/v1/highlights/detect 需要配置 ARK_API_KEY 和 ARK_MODEL；其他本地数据接口不需要模型 Key。

这是一次静态 API 快照；路由变更后需要重新生成本文件。
