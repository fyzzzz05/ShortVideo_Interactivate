后端20天落地计划（仅后端，具体可执行）

目标：20天内交付可演示后端，支持高光检测双模式、同款识别外链、场景互动映射、剧末人格测试，并完成本地+云上部署。

技术栈（固定建议）

  • Python 3.11 + FastAPI + Uvicorn
  • PostgreSQL 16（本地可先 SQLite，D8 前切 PG）
  • SQLAlchemy 2.x + Alembic
  • Redis 7 + slowapi（限流）
  • Celery + Redis（离线任务）
  • httpx（模型服务调用）
  • structlog + Prometheus + Grafana
  • Docker + docker-compose
  • pytest + pytest-asyncio

核心接口

  • GET /dramas
  • GET /episodes/{episode_id}/events?mode=offline|hybrid
  • POST /events/realtime-detect
  • POST /interactions/click
  • POST /interactions/like
  • GET /interactions/summary?episode_id=...
  • POST /shop/search-link
  • GET /quiz/{episode_id}/profile
  • POST /quiz/submit

20天排期（后端）

  1. D1-D2：工程骨架、配置、日志、Alembic、基础表。
  2. D3-D4：离线事件主链路与导入脚本。
  3. D5-D6：互动写入与聚合、幂等与去重。
  4. D7-D8：实时检测接口、超时重试、切 PostgreSQL。
  5. D9-D10：hybrid 合并、去重、熔断开关。
  6. D11-D12：同款识别外链生成。
  7. D13-D14：小游戏/特效映射规则配置化。
  8. D15-D16：人格测试评分与负面角色过滤。
  9. D17-D18：限流、监控、日志追踪、压测优化。
  10. D19-D20：Docker化、云部署、回归与交付文档。

测试与验收

  • 功能：offline/hybrid 都可用，互动计数正确。
  • 鲁棒性：实时失败自动回退离线，不阻塞主链路。
  • 一致性：按 dedup_key + event_type 去重。
  • 性能：/events 在演示数据量下 P95 < 300ms。

默认假设

  • 模型 API 可用，密钥通过环境变量管理。
  • 同款仅做“识别标签 → 搜索外链”，不做成交闭环。
  • 实时不稳时可关闭开关，保离线主链路按时交付。
